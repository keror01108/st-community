# 커뮤니티 피드 (SillyTavern 확장)

채팅을 보고 커뮤니티 반응 글을 만들어 주는 확장입니다.

- **작품 반응 모드**: 채팅을 연재 중인 작품으로 보고, 독자·팬들의 반응(감상, 떡밥 추리, 커플링, 불만, 밈)을 만듭니다.
- **세계관 속 모드**: 이야기 세계에 커뮤니티가 있다고 보고, 그 세계 사람들의 일상 글과 캐릭터·유저를 목격하거나 아는 사람들의 글을 만듭니다.
- 커뮤니티: 네이버 카페, 디시인사이드, 투디갤, 블라인드, 에브리타임, Reddit, X(트위터), 2ch/5ch, 웨이보, 바이두 티에바, 디스코드 — 각각 실제 사이트 느낌의 화면으로 보여줍니다.

## 설치

1. 실리태번 위쪽 **확장 메뉴(블록 모양 아이콘)** → **확장 프로그램 설치 (Install extension)**를 누릅니다.
2. 주소 칸에 `https://github.com/keror01108/st-community` 를 붙여 넣고 설치합니다.
3. 채팅창 왼쪽 마법봉 메뉴에 **커뮤니티** 항목이 생기면 성공입니다.

업데이트는 확장 관리에서 이 확장 옆의 업데이트 버튼으로 할 수 있어요.

## 처음 설정

- 아무 설정 없이도 지금 연결된 메인 API로 생성돼요.
- 커뮤니티에만 다른 모델을 쓰려면 커뮤니티 창 위쪽 🔌 **API 설정**에서 연결을 고르세요 (아래 "API 설정" 참고).
  - 실리태번 **연결 프로필**을 쓰려면 기본 확장 Connection Manager(연결 관리자)가 켜져 있어야 해요.
  - 프로필 없이 주소·키를 직접 넣어 API를 추가할 수도 있어요.
- 고른 연결은 커뮤니티 생성에만 쓰여요. 본편 채팅의 연결은 바뀌지 않아요.

## 사용법 (v1.26.3)

### 커뮤니티 창

- 입력창 왼쪽 **마법봉 메뉴 → 커뮤니티**를 누르면 창이 열립니다.
- 위쪽 버튼: ✏️ 직접 글쓰기 · ⌃ 메뉴 접기 · 🔌 API 설정 · ⚙ 설정 · ◐ 화면 테마 · 📚 월드 인포 · 🕘 지난 피드 · 📌 반영 중인 글 · ✕ 닫기
- 모드와 커뮤니티를 고르고 **생성**. 주제 칸에 "방금 고백 장면 반응"처럼 요청을 적을 수도 있어요.
- 생성하면 글 **제목 목록**만 먼저 나와요. 제목을 누르면 본문과 댓글·레스가 펼쳐지고, 다시 누르면 접혀요. 피드 위쪽 **모두 펴기 / 모두 접기**로 한 번에 바꿀 수 있어요.
  - 내가 쓴 글, 다음 스레로 이동한 글, 📌 목록에서 연 글은 펼쳐진 채로 열려요.
  - 투디갤은 원래 목록형이고, 디스코드는 채널을 골라 보는 방식이라 접지 않아요.

### 커뮤니티 · 모드 · 판

- 위쪽에서 커뮤니티나 모드를 바꾸면 **그 커뮤니티 + 모드의 최신 피드**가 바로 나와요. 다른 커뮤니티 글은 섞이지 않아요. 아직 없으면 빈 게시판이 나와요.
- **글 주제는 판(갤러리·板)처럼 따로 나뉘어요.** 자유로 생성한 글과 공포로 생성한 글은 다른 판에 쌓이고, 주제 칩을 바꾸면 그 판이 바로 나와요. 여러 주제를 같이 고르면(공포 + 썰) 그 조합이 하나의 판이에요.
- 주제 줄 아래 **판** 줄에 지금 커뮤니티·모드에서 만든 판이 모두 나와요 (조합 판 포함, 옆 숫자는 지금 보이는 피드의 글 수). 눌러서 바로 그 판으로 가요.
- 같은 판에서 다시 **생성**하면 새 피드가 보이고, 이전 피드는 🕘 지난 피드에 남아요. 같은 판에 이어서 쌓으려면 피드 맨 아래 **이 게시판에 글 더 불러오기**를 누르세요.
- **디스코드는 주제마다 서버가 따로**예요(판 줄 이름도 "서버"). 같은 주제로 다시 생성하면 지금 서버에 새 채널이 열려서, 채널·DM·내 메시지가 한 서버에 계속 남아요.
- 창을 닫았다 열면 마지막으로 보던 곳으로 열려요. 자동 생성 글은 보고 있던 화면을 바꾸지 않아요.
- 설정에서 주제 적용을 "자동 생성만"으로 두면 판을 나누지 않아요.

### 내 카페·갤러리 만들기

- 커뮤니티 줄 아래 **카페 / 갤러리 / 서브레딧 / 板 / 서버 / 라운지 / 학교…** 줄에서 내가 만든 공간을 고를 수 있어요. **기본**은 지금처럼 AI가 어울리는 곳을 정해요.
- **＋ 만들기**: 이름(예: "별의 노래 게임 카페"), 어떤 곳인지 설명(회원 성향, 분위기, 말투 등), 그 공간의 배경(아래 참고)을 정해요. 같은 화면에서 고치기·지우기도 돼요.
- 공간을 고른 채로 **생성**하면 그 카페·갤러리 안의 글이 만들어져요. 그 안에서도 **글 주제(연애, 자유, 공포…)와 판은 그대로** 쓸 수 있어요. 예: 게임 카페 안의 "연애" 판, "자유" 판.
- 공간은 커뮤니티마다 따로예요(네이버 카페로 만든 건 네이버 카페 줄에만). 모든 채팅에서 같이 쓰여요.
- 공간을 고르면 직접 글쓰기 창의 "게시판 이름" 칸은 숨겨지고, 그 공간에 올라가요.
- 공간 이름을 고치면 그 공간의 피드에도 새 이름이 보여요. 공간을 지워도 거기서 만든 피드는 🕘 지난 피드에 남아요.

### 커뮤니티 배경

- 생성 줄의 **배경** 칸에서 이 커뮤니티가 어느 나라·어떤 세계에 있는지 정해요. 채팅마다 따로 저장돼요.
  - **이야기대로**: 본 채팅 배경을 따라요 (기본).
  - **나라 선택**(한국, 일본, 미국, 중국…): 예를 들어 채팅은 한국 이야기여도, 커뮤니티 사람들은 일본에 사는 사람들로 반응해요. 이야기 속 사건은 "바다 건너 소식"처럼 다뤄요.
  - **직접 입력…**: "2087년 화성 식민지", "조선 후기 한양" 같은 배경을 직접 적어요.
- 내가 만든 카페·갤러리에 배경을 따로 정해 두면 그게 채팅 배경보다 먼저 적용돼요. "채팅 설정 따라가기"로 두면 위 배경 칸을 따라요.
- 배경은 글쓴이들이 어디 사는지, 무엇을 아는지만 바꿔요. 글 언어는 그대로 **언어** 칸을 따라요.

### 직접 글쓰기 · 댓글

- ✏️ 버튼: **직접 글쓰기**. 제3자(모브) / 유저(페르소나 이름) / **캐릭터** 중 누구로 쓸지 고르고 닉네임을 정할 수 있어요.
  - 캐릭터로 쓸 때는 캐릭터 이름을 적어요. 1:1 채팅이면 자동으로 채워지고, 단체 채팅(다인봇)이면 멤버 이름이 후보로 떠요. 목록에 없는 이름도 그냥 적으면 돼요.
  - 지금 보고 있는 판에 올라가요.
  - "올리고 바로 반응 생성"을 켜 두면 올리자마자 댓글/레스가 달려요.
  - **✨ AI로 쓰기**: 고른 신분의 말투와 입장으로 AI가 제목·본문을 채워 줘요. 지시 칸이 비어 있으면 고른 글 주제에 맞게, 지시를 적으면 그대로 따라요. 본문 칸에 글이 있으면 그걸 다듬어요. 댓글·답글 창에도 있어요.
- **닉네임**: 칸을 비우면 커뮤니티에 어울리는 닉네임이 자동으로 붙어요.
  - 이름이 보이는 커뮤니티(카페·레딧·X·웨이보·티에바·디스코드)는 랜덤 닉네임, 블라인드는 랜덤 직장. 설정에서 "AI가 사람·글에 맞는 닉네임"을 고르면 유저·캐릭터 성격과 글 내용에 맞게 지어 줘요 (짧은 요청 1번).
  - 익명 커뮤니티는 원래 방식대로: 디시·투디갤 `ㅇㅇ`(+IP/코드), 2ch `名無しさん`(+ID), 에브리타임 `익명N`·`익명(글쓴이)`.
  - **한 글 안에서는 같은 신분이 같은 닉네임**을 써요. 1번 글에 유저로 "B"라고 썼다면, 1번 글 댓글 창에서 유저를 고르면 B가 미리 채워져요 (디시 IP·2ch ID도 그대로). 모브·유저·캐릭터(이름별)를 따로 기억해요. 디스코드는 한 서버 안에서 채널이 달라도 같은 닉네임을 써요.
  - ✨ AI로 쓰기를 쓰면 닉네임 칸이 비어 있을 때 어울리는 닉네임도 같이 채워 줘요.
- 글 아래 버튼
  - **댓글 쓰기 / 레스 쓰기**: 직접 댓글을 달면 그에 대한 반응이 이어서 올라와요. 댓글 옆 **답글**로 특정 댓글에 답할 수 있고, 2ch는 레스 번호(>>3)를 누르면 앵커가 입력돼요.
  - **댓글 더 보기 / 스레드 이어가기**: 내가 아무것도 안 써도 대화가 이어지게 추가 생성해요.
  - 👁 지켜보기, 🔗 다른 글 참고, 📌 반영, 🗑 삭제 (아래 참고)
- 내가 쓴 글·댓글에는 보라색(캐릭터면 청록색) 배지가 붙어요.

### 지우기

- AI가 만든 글·스레·채널도 🗑 버튼으로 하나씩 지울 수 있어요. 댓글·레스·메시지는 옆의 **삭제**로 지워요. 둘 다 확인 창이 떠요.
- 반영 중이던 글을 지우면 본 채팅 반영에서도 빠져요. 후속 스레 연결, 디스코드 답장 표시도 알아서 맞춰져요.
- 2ch 레스를 지워도 다른 레스 본문 속 `>>번호`는 바뀌지 않아요.

### 2ch · 레딧 스레드

- 한 스레드는 최대 1000레스(설정에서 변경 가능)까지만 이어져요. 꽉 차면 "1000을 넘었습니다" 표시와 함께 닫히고, **후속 스레 작성** 버튼으로 Part2 스레가 세워져요. 이전/다음 스레 링크로 오갈 수 있어요.

### 디스코드

- 서버 하나에 글이 채널(#잡담, #스포일러…)로 나뉘어 있고, 채팅처럼 메시지가 이어져요. 답장한 메시지는 위에 인용이 붙어요.
- **DM**: 채널 목록 아래 "다이렉트 메시지 ＋" 또는 메시지 옆 **DM** 링크. 보내는 사람(모브/유저/캐릭터)과 받는 사람(캐릭터/유저/서버 멤버)을 고르면 상대가 답장해요. 첫 메시지를 비우면 상대가 먼저 말을 걸어요. ✨ AI로 쓰기도 돼요.
- DM도 👁 지켜보기(자동으로 상대가 메시지 보냄)와 📌 반영(본편에 "둘이 이런 DM을 주고받았다")을 각각 켜고 끌 수 있어요.

### 투디갤

- 깡통 스타일 게시판이에요. 창이 넓으면 왼쪽에 카테고리 카드, 좁으면 위쪽에 카테고리 칩이 나와요.
- 최신/개념글 정렬과 검색, 노란 개념글 배너, 필터(전체·개념·내 글)가 있고, 줄을 누르면 본문과 댓글이 펼쳐져요.
- 오른쪽 아래 **글쓰기** 버튼은 지금 고른 카테고리로 글쓰기 화면을 열어요. 모두 "ㅇㅇ" + 4자리 코드로 표시돼요.

### 블라인드 · 에브리타임

- **블라인드**: 직장인 익명 커뮤니티 느낌이에요. 글과 댓글마다 글쓴이의 **회사 이름**(세계관에 맞는 직장)과 닉네임 코드가 붙고, 채널(블라블라·회사생활·이직·커리어·연애…)로 나뉘어요. 글쓴이가 단 댓글엔 "작성자" 표시가 붙어요. 직접 쓸 때는 닉네임 칸에 회사 이름을 적으면 돼요.
- **에브리타임**: 대학생 커뮤니티 느낌이에요. 위쪽은 학교 이름, 글은 게시판(자유·비밀·새내기·졸업생·정보…)으로 나뉘고, 댓글은 **익명1, 익명2…** 와 **익명(글쓴이)**로 나와요. 공감 10개 이상이면 HOT 표시가 붙어요. 내가 모브로 댓글을 달면 번호가 이어서 붙어요.

### 글 주제

- 주제 칩(공포, 낚시, 웃음, 연애, 고민…)을 고르면 새 글·스레드가 그 주제로 만들어지고, 그 주제의 판에 쌓여요. 자동 생성에도 적용돼요.
- 여러 개를 고르면 "글마다 하나씩"(골고루 배정) 또는 "섞어서"를 고를 수 있어요.
- 주제 줄 끝의 ＋ 버튼으로 **주제 추가**(이름 + 설명)와 삭제를 해요. 예) 이름 `자캐 목격담`, 설명 `캐릭터를 길에서 봤다는 글`
- "기본 주제 다시 넣기"는 지운 기본 주제만 다시 넣어요.
- 댓글·레스 이어가기에는 적용되지 않아요.

### 월드 인포 (📚)

- 채팅마다 참고 방식을 골라요: 사용 안 함 / 자동(채팅에서 지금 켜지는 항목) / 직접 고른 항목만 / 자동 + 직접 고른 항목
- 책을 여러 개 펼쳐서 항목을 체크하세요. 책마다 전체 선택 · 켜진 항목만 · 선택 해제가 있어요.
- 고른 항목은 키워드와 상관없이 내용 전체가 들어가고, 실리태번 본편 설정은 바뀌지 않아요.

### 반영 (📌)

- 마음에 드는 글을 본편 AI에게 알려줍니다.
  - 세계관 속 글 → "세계에 돌고 있는 소문"으로 전달
  - 작품 반응 글 → "독자 반응, 캐릭터는 모름"으로 전달 (4차 벽 깨지 않도록 지시)
  - 캐릭터/유저가 쓴 글이 들어 있으면 "그 캐릭터가 이런 글을 썼고 이런 반응이 달렸다"로 들어가요.
- 📌 목록에서 하나씩 해제하거나 전체 반영을 끌 수 있고, 항목을 누르면 그 글이 펼쳐진 채로 열려요.

### 자동 생성

- 설정 → "본 채팅 진행에 맞춰 자동 생성". AI 답변이 올 때마다 세요.
  - **새 글·새 스레**: N번마다 새 피드를 만들어요. "자동으로 만든 글은 바로 지켜보기"를 켜면 그 글들도 자동으로 이어가요.
  - **레스·댓글**: 👁 **지켜보기**를 켠 글만 M번마다 이어가요. 지켜보는 글이 많으면 오래 안 이어간 글부터 돌아가요.
  - 지켜보던 2ch·레딧 스레가 꽉 차면 후속 스레를 세우고 지켜보기를 그쪽으로 옮겨요.
  - 직접 생성 중일 때 차례가 오면 끝날 때까지 기다려요. 창이 닫혀 있으면 마법봉 메뉴에 새 글 수가 표시돼요.

### 다른 게시글 참고 (🔗)

- 같은 채팅·커뮤니티·모드의 최근 글 몇 개를 같이 보여 줘서 "다른 스레에서 봤는데" 같은 반응이 나오게 해요.
  - 전체: 설정의 "모든 생성에서 다른 게시글 참고"
  - 이 글만: 글 아래 🔗 버튼

### 추론 최소화

- ⚙ 설정 → **추론 최소화**: 생각(추론)하는 모델이 추론을 최소로 하게 해요. 빨라지고 토큰이 줄지만 글 품질이 조금 떨어질 수 있어요.
  - 연결 프로필·직접 추가한 API: 실리태번의 가장 낮은 추론 강도(min)로 보내요 (OpenAI 추론 모델 minimal, Gemini Flash 생각 0, Claude 최소 예산 등). 생각 내용 받기도 꺼요.
  - 메인 API: 요청 설정을 바꿀 수 없어서 "바로 답하라"는 지시문만 붙어요. 메인 API 쪽 추론 강도는 실리태번 AI 응답 설정에서 바꿔 주세요.
  - 지시문은 프롬프트 편집의 "추론 최소화 지시"에서 고칠 수 있어요.

### 주변 인물(NPC)

- ⚙ 설정 → **주변 인물(NPC)이 직접 글 쓰기**: 세계관 속 모드에서 이야기에 나오는 조연(친구·가족·동료 등)이 직접 글·댓글을 달지 정해요. "AI가 알아서 / 쓰게 하기 / 쓰지 않게 하기". 작품 반응 모드에는 영향이 없어요.

### 장기기억·요약 확장과 함께 쓰기

- Memoria, 코끼리를 생각하지마, VectFox, 실리태번 기본 요약(Summarize)·벡터 저장소처럼 본 채팅에 기억을 넣는 확장의 내용을 커뮤니티 생성에도 넣어요. (설정 → "장기기억·요약 확장 내용 포함", 기본 켜짐)
- 이 확장들은 본 채팅 답변을 만들 때 기억을 갱신하고, 커뮤니티는 그 마지막 내용을 읽어요. 요약한 옛 메시지를 숨기는 확장을 써도 그 줄거리를 알 수 있어요.
- 설정의 "읽을 항목"에서 확장별로 켜고 끌 수 있어요. 기억·요약으로 보이는 건 자동으로 켜지고, 작가 노트나 변수 규칙 같은 다른 확장 프롬프트는 꺼진 채로 나와요.

### 설정 (⚙)

- 커뮤니티 창 위쪽 ⚙ 버튼으로 확장 탭의 설정을 그대로 열 수 있어요. 같은 설정이라 어느 쪽에서 바꿔도 똑같이 적용돼요.

### 슬래시 명령어

- `/community` (창 열기), `/community platform=fivech mode=world 축제 당일 반응` (바로 생성)
  - platform: `naver` `dcinside` `reddit` `twitter` `fivech` `weibo` `discord` `tdgall` `blind` `everytime` `tieba`
  - mode: `meta`(작품 반응) `world`(세계관 속)

## API 설정 (🔌)

- **연결 고르기**: 메인 API · 실리태번 연결 프로필 · 직접 추가한 API 중에서 골라요. 확장 설정의 "생성에 쓸 연결"과 같은 값이에요. **연결 테스트**로 응답이 오는지 바로 확인할 수 있어요.
- **프로필 모델 따로 정하기**: 연결 프로필을 고르면 모델 칸이 나와요. 비워 두면 프로필 모델, 적으면 커뮤니티 생성에만 그 모델을 써요. **목록 불러오기**를 누르면 아래에 모델 드롭다운이 생겨요 (프록시를 쓰는 프로필은 직접 적기).
- **최대 응답 토큰**: 글이 중간에 끊기면 늘려 주세요.
- **번역에 쓸 연결**: 기본은 글을 만들 때 같이 번역해요. 다른 연결을 고르면 글을 먼저 만들고, 그 연결이 뒤이어 새 글의 제목·본문·댓글을 번역해요. 생성 프롬프트가 짧아지고 번역은 싼 모델에 맡길 수 있어요. 연결 프로필이나 직접 추가한 API를 고르면 **번역 모델** 칸과 **목록 불러오기**가 나와서, 생성과 다른 모델로 번역할 수 있어요 (비워 두면 그 연결의 모델). **번역 테스트** 버튼으로 바로 확인할 수 있어요. 번역 언어는 ⚙ 설정의 "번역 함께 생성"에서 골라요.
- **API 직접 추가**: 이름, 형식, 주소, 키(또는 프록시 비밀번호), 모델을 적고 저장해요. 저장 전에 목록 불러오기와 테스트를 해 볼 수 있어요.
  - **OpenAI 호환**: OpenAI 공식(`https://api.openai.com/v1`), 리버스 프록시, OpenRouter, DeepSeek, 로컬 서버 등. 주소는 `/v1`까지만.
  - **Claude (Anthropic) 호환**: Anthropic 공식 또는 Claude 리버스 프록시. 주소는 `/v1`까지만.
  - **Gemini (Google) 호환**: Google AI Studio 또는 Gemini 리버스 프록시.
  - **Vertex AI (Google Cloud)**: 인증 방식을 골라요.
    - **Express / Full**: 실리태번 API 연결 화면(Chat Completion → Google Vertex AI)에 저장해 둔 Vertex API 키나 서비스 계정 JSON을 그대로 써요. 키를 이 확장에 따로 적지 않아요. 리전(기본 `us-central1`, `global` 가능)과 Express 프로젝트 ID(선택)를 적어요.
    - **리버스 프록시**: 주소와 비밀번호를 적어요 (실리태번 프록시 칸에 넣는 주소 그대로).
    - 실리태번이 Vertex 모델 목록을 주지 않아서, 목록 불러오기는 자주 쓰는 Gemini 모델 이름을 보여 줘요. 다른 이름은 직접 적으면 돼요.
  - 요청은 실리태번 서버를 거쳐 보내요 (실리태번의 리버스 프록시 기능과 같은 방식). 그래서 브라우저 CORS 문제가 없어요.
  - 키는 실리태번 설정 파일(settings.json)에 저장돼요. 실리태번이 프록시 비밀번호를 저장하는 방식과 같으니, 설정 파일을 다른 사람과 공유하지 마세요.

## 언어 · 번역

- **생성 언어**: 커뮤니티 원어(2ch=일본어, 웨이보·티에바=중국어, Reddit=영어…) 또는 한국어·영어·일본어·중국어·스페인어·러시아어 등 목록에서 고르거나 **직접 입력**(예: Catalan, 경상도 사투리 한국어). 생성 버튼 옆에서도 바꿀 수 있어요.
- 웨이보·티에바·2ch처럼 외국 커뮤니티를 다른 언어로 생성하면, 원어 단어나 괄호 원문을 섞지 않고 자연스럽게 현지화해서 써요. 한국 커뮤니티 은어(원덬, 덬, 념글 등)도 쓰지 않아요.
  - 화면의 고정 문구도 그 언어로 바뀌어요 (예: 웨이보 "来自 微博客户端" → "웨이보 앱", 티에바 "楼主 / 2楼" → "글쓴이 / 2층", 2ch "名前：" → "이름:").
  - 피드마다 만든 때의 언어를 기억해서, 나중에 언어 설정을 바꿔도 이어지는 댓글은 원래 언어로 나와요.
- **번역 언어**: 번역 보기에 쓸 언어예요 (⚙ 설정).
- **번역 시점**: "생성할 때 자동으로"(기본) 또는 "글의 번역 버튼을 누를 때만". 버튼으로만 하면 생성 프롬프트가 짧아지고, 보고 싶은 글만 번역해요.
- **글마다 번역 버튼**: 글을 펼치면 아래에 **번역** 버튼이 있어요. 누르면 그 글(제목·본문·댓글)만 번역하고, 다시 누르면 **원문**으로 돌아가요. 번역 언어를 안 골랐으면 한국어로 번역해요.
  - ↻ **재번역**: 그 글을 처음부터 다시 번역해요.
  - ✎ **번역 수정**: 글 제목·본문 번역을 직접 고쳐요. 댓글은 옆의 **번역 수정**으로 하나씩 고쳐요.
  - 피드 위쪽 **번역** 버튼은 피드 전체를 한 번에 번역 보기 / 원문 보기로 바꿔요.
- **번역 보기**: "번역문만" 또는 "원문 위 · 번역문 아래"(원문과 함께 보기).
- 번역에 쓸 API·모델은 🔌 API 설정의 "번역에 쓸 연결"에서 골라요. 따로 안 고르면 생성에 쓰는 연결로 번역해요.
## 본 채팅에서 읽는 것 / 안 읽는 것

- 숨긴(hide) 메시지와 시스템 메시지는 읽지 않아요. 내레이터 메모(/sys)도 기본으로 빼요. (설정에서 켜고 끌 수 있어요)
- 상태창 같은 태그는 **태그와 안의 내용을 통째로** 빼요. 기본 목록: `status`, `statusbar`, `details`, `UpdateVariable`, `think`, `상태창`, `状态栏` 등. 설정의 "본 채팅에서 읽지 않을 태그"에서 쉼표로 추가·삭제할 수 있어요. (예: 카드가 `<StatusBlock>`을 쓰면 `StatusBlock` 추가)
- 코드 블록(``` 안, 상태창 HTML 카드 포함)과 HTML 주석도 빼요.
- 장기기억·요약 확장이 넣는 기억은 읽어요 (위 "장기기억·요약 확장과 함께 쓰기").

## 피드 저장 위치

- 피드는 채팅 파일이 아니라 **실리태번 서버의 사용자 파일 폴더**에 저장돼요: `SillyTavern/data/<사용자>/user/files/stcm-feed-*.json` (채팅마다 1개).
  - 같은 서버에 접속하면 PC와 폰에서 같은 피드가 보여요.
  - 채팅 파일에는 그 파일을 가리키는 번호와 📌 반영 목록, 채팅별 설정(월드 인포 선택 등)만 남아요.
  - 예전 버전에서 채팅 파일 안에 저장돼 있던 피드는 그 채팅을 처음 열 때 자동으로 옮겨져요.
- **브랜치·체크포인트**: 갈라진 채팅을 처음 열면, 갈라진 시점까지 있던 피드가 그 채팅 전용 파일로 복사돼요. 그 뒤로는 서로 영향을 주지 않아요. 갈라진 시점 이후에 만든 피드와 그 반영(📌)은 따라가지 않아요.
- 채팅 이름을 바꿔도 같은 파일을 계속 써요.
- 채팅을 지우면 파일은 바로 지우지 않고 "정리 대상"으로 표시해요. (그 채팅에서 갈라졌는데 아직 열지 않은 브랜치가 쓸 수 있어서요) 설정의 **삭제된 채팅의 피드 파일 정리** 버튼으로 지울 수 있어요.
- 🕘 지난 피드: 이 채팅에서 만든 피드를 모두 볼 수 있어요 (채팅마다 최대 30개 저장).
- 채팅 백업·내보내기에는 피드가 들어가지 않아요. 아래 **피드 내보내기**를 쓰거나 위 폴더를 같이 복사하세요.
- **피드 내보내기 / 불러오기**: 🕘 지난 피드 화면 위쪽 버튼.
  - 내보내기: 이 채팅의 피드 전부와 📌 반영 목록, 그 피드를 만든 **내 카페·갤러리**(이름·설명·배경)를 `community-feed_채팅이름_날짜.json`으로 내려받아요. API 키는 들어가지 않아요.
  - 불러오기: 내보낸 파일(또는 서버 폴더의 `stcm-feed-*.json`)을 고르면 **합치기** / **바꾸기**를 고를 수 있어요. 반영 목록을 같이 불러올지도 고를 수 있어요.
  - 파일에 카페·갤러리가 들어 있으면 "카페·갤러리도 불러오기"를 고를 수 있어요. 같은 커뮤니티에 같은 이름의 카페가 이미 있으면 새로 만들지 않고 그 카페에 넣어요.
  - 다른 채팅에서 내보낸 파일도 불러올 수 있어요. 불러온 파일의 내용은 하나하나 검사해서 안전한 형태로만 들여와요.

## 화면

- 휴대폰(세로·가로), 태블릿, PC 화면에 맞춰 크기가 바뀌어요. 휴대폰에서는 전체 화면으로 열려요.
- 위쪽 ⌃ 버튼으로 모드·커뮤니티·주제 줄을 접고 펼 수 있어요. 높이가 낮은 화면에서는 처음엔 접혀 있고, 접기/펴기 선택은 "낮은 화면"과 "보통 화면"에 따로 기억돼요.
- 반영·댓글 쓰기·답글·번역·이어가기를 눌러도 보고 있던 위치가 그대로 유지돼요.
- **간략한 화면** (설정 → 화면 테마 아래): 켜면 메뉴가 짧아져요. 끄면 원래 화면이에요.
  - 커뮤니티·카페·판 줄이 `네이버 카페 › 게임 카페 ▾` 한 칸으로 합쳐져요. 누르면 아래에서 고르는 창이 올라와요 (커뮤니티를 고르면 창이 그대로 있고, 카페·판을 고르면 닫혀요).
  - 모드는 그 칸 옆 버튼 두 개로 (휴대폰에선 아이콘만, 넓은 화면에선 이름도).
  - 지난 피드·반영 중인 글·월드 인포·화면 테마·메뉴 접기는 위쪽 **⋯** 버튼 안으로 들어가요. 반영 중인 글 수는 ⋯ 위에 표시돼요.
  - 언어·배경은 생성 칸 아래 작은 글씨로 바뀌어요. 누르면 원래처럼 고를 수 있어요.
- ◐ 버튼(또는 설정의 "화면 테마")으로 **테마 따라가기 → 라이트 → 나이트** 순서로 바뀌어요.
  - 테마 따라가기: 실리태번 테마 색을 따라가요. 커뮤니티 상징색(네이버 초록 등)은 유지돼요.
  - 라이트 / 나이트: 각 커뮤니티의 밝은 화면 / 어두운 화면 스타일로 보여요.

## 프롬프트 편집

설정 → **프롬프트 편집**에서 항목을 골라 고칠 수 있어요. (시스템 프롬프트, 두 모드 지시, 이어서 생성 지시, 내 글에 반응하라는 지시, 언어/번역 지시, 주변 인물(NPC) 지시, 내 카페·갤러리 지시, 배경 지시, 출력 형식, 커뮤니티별 스타일)

- 변수: `{{char}}` `{{user}}` `{{platform}}` `{{language}}` `{{translation}}` `{{count}}` `{{comments}}`, 공간·배경 항목은 `{{space}}` `{{about}}` `{{country}}` `{{setting}}`, 실리태번 매크로도 사용 가능
- 비우거나 "이 항목 기본값으로"를 누르면 기본값으로 돌아가요. 고친 항목은 새 버전의 기본값 변경이 적용되지 않으니, 업데이트 후 이상하면 기본값으로 되돌려 보세요.
- 출력 형식 항목을 고칠 때는 JSON 필드 이름(`posts`, `comments`, `reply_to`, `title`, `title_tr`, `body`, `body_tr` 등)을 바꾸지 마세요. 확장이 이 이름으로 읽어요.

## 잘 안 될 때

- "응답을 해석하지 못했어요" → 최대 응답 토큰을 늘리거나 글/댓글 수를 줄여 보세요. 원본 응답 보기에서 AI가 뭘 보냈는지 확인할 수 있어요.
- "생성 실패" → 오류 창의 **API 설정 열기**에서 연결과 연결 테스트를 확인해 보세요.
- 응답이 토큰 한도에서 잘려도, 끝까지 완성된 글·댓글은 살려서 보여 줘요.
- 사고(thinking) 모델은 토큰을 많이 먹으니 최대 토큰을 넉넉히 주세요.
- 확장이 안 보이면 폴더 이름/위치와 브라우저 콘솔(F12)의 빨간 오류를 확인하세요.

# 커뮤니티 피드 (SillyTavern 확장)

채팅을 보고 커뮤니티 반응 글을 만들어 주는 확장입니다.

- **작품 반응 모드**: 채팅을 연재 중인 작품으로 보고, 독자·팬들의 반응(감상, 떡밥 추리, 커플링, 불만, 밈)을 만듭니다.
- **세계관 속 모드**: 이야기 세계에 커뮤니티가 있다고 보고, 그 세계 사람들의 일상 글과 캐릭터·유저를 목격하거나 아는 사람들의 글을 만듭니다.
- 커뮤니티: 네이버 카페, 디시인사이드, Reddit, X(트위터), 2ch/5ch, 웨이보, 바이두 티에바 — 각각 실제 사이트 느낌의 화면으로 보여줍니다.

## 설치

1. `st-community` 폴더를 통째로 아래 중 한 곳에 넣습니다.
   - `SillyTavern/data/default-user/extensions/` (사용자 이름이 다르면 `default-user` 대신 그 이름)
   - 또는 `SillyTavern/public/scripts/extensions/third-party/`
2. 실리태번을 새로고침합니다.
3. 확장 메뉴(블록 모양 아이콘)에 **커뮤니티 피드** 항목이 생기면 성공입니다.

## 처음 설정

1. 실리태번 기본 확장인 **Connection Manager(연결 관리자)**가 켜져 있어야 프로필을 고를 수 있어요.
2. API 연결 화면에서 커뮤니티용으로 쓸 모델을 연결한 뒤 **연결 프로필로 저장**합니다. (싸고 빠른 모델 추천)
3. 확장 메뉴 → 커뮤니티 피드 → **생성에 쓸 연결 프로필**에서 그 프로필을 고릅니다. 비워 두면 지금 메인 API로 생성합니다.
4. 프로필을 바꿔도 본편 채팅의 연결은 바뀌지 않습니다.

## 사용법 (v1.4)

- 입력창 왼쪽 **마법봉 메뉴 → 커뮤니티**를 누르면 창이 열립니다.
- 모드와 커뮤니티를 고르고 **생성**. 주제 칸에 "방금 고백 장면 반응"처럼 요청을 적을 수도 있어요.
- ✏️ 버튼: **직접 글쓰기**. 제3자(모브) / 유저(페르소나 이름) / **캐릭터** 중 누구로 쓸지 고르고 닉네임을 정할 수 있어요.
  - 캐릭터로 쓸 때는 캐릭터 이름을 적어요. 1:1 채팅이면 자동으로 채워지고, 단체 채팅(다인봇)이면 멤버 이름이 후보로 떠요. 목록에 없는 이름도 그냥 적으면 돼요.
  - 캐릭터/유저가 쓴 글이나 댓글이 들어간 글을 📌 반영하면, 본편에 "그 캐릭터가 그 커뮤니티에 이런 글을 썼고, 이런 반응이 달렸다"는 내용으로 들어가요.
  - 지금 보고 있는 피드와 같은 커뮤니티·모드면 그 피드에 올라가고, 아니면 새 피드가 만들어져요.
  - "올리고 바로 반응 생성"을 켜 두면 올리자마자 댓글/레스가 달려요.
- 글 아래 버튼
  - **댓글 쓰기 / 레스 쓰기**: 직접 댓글을 달면 그에 대한 반응이 이어서 올라와요. 댓글 옆 **답글**로 특정 댓글에 답할 수 있고, 2ch는 레스 번호(>>3)를 누르면 앵커가 입력돼요.
  - **댓글 더 보기 / 스레드 이어가기**: 내가 아무것도 안 써도 대화가 이어지게 추가 생성해요.
  - 내가 쓴 글·댓글에는 보라색 배지가 붙고, 삭제할 수 있어요.
- **2ch·레딧 스레드 제한**: 한 스레드는 최대 1000레스(설정에서 변경 가능)까지만 이어져요. 꽉 차면 "1000을 넘었습니다" 표시와 함께 닫히고, **후속 스레 작성** 버튼으로 Part2 스레가 세워져서 이어져요. 이전/다음 스레 링크로 오갈 수 있어요.
- 피드 맨 아래 **이 게시판에 글 더 불러오기**: 같은 게시판에 새 글을 더 만들어요.
- 📚 버튼: **참고할 월드 인포**를 채팅마다 고를 수 있어요.
  - 참고 방식: 사용 안 함 / 자동(채팅에서 지금 켜지는 항목) / 직접 고른 항목만 / 자동 + 직접 고른 항목
  - 책을 여러 개 펼쳐서 항목을 체크하세요. 책마다 전체 선택 · 켜진 항목만 · 선택 해제가 있어요.
  - 이 채팅·캐릭터·전역에 연결된 책은 위쪽에 표시돼요. 고른 항목은 키워드와 상관없이 내용 전체가 들어가고, 실리태번 본편 설정은 바뀌지 않아요.
- **글 주제**: 커뮤니티 창의 주제 칩(공포, 낚시, 웃음, 연애, 고민…)을 골라 두면 새 글·스레드가 그 주제로 만들어져요. 자동 생성에도 적용돼요.
  - 여러 개를 고르면 "글마다 하나씩"(골고루 배정) 또는 "섞어서"를 고를 수 있어요.
  - 주제 줄 끝의 ＋ 버튼으로 **주제 추가**(이름 + 설명)와 삭제를 해요. 추가한 주제는 바로 선택돼요. 예) 이름 `자캐 목격담`, 설명 `캐릭터를 길에서 봤다는 글`
  - "기본 주제 다시 넣기"는 지운 기본 주제만 다시 넣어요. 내가 추가한 건 그대로 둬요.
  - "자동 생성만"으로 바꾸면 직접 누르는 생성에는 적용되지 않아요.
  - 댓글·레스 이어가기에는 적용되지 않아요.
- 🕘 버튼: 이 채팅에서 만든 지난 피드 (채팅마다 최대 30개 저장)
- 📌 **반영** 버튼: 마음에 드는 글을 본편 AI에게 알려줍니다.
  - 세계관 속 글 → "세계에 돌고 있는 소문"으로 전달
  - 작품 반응 글 → "독자 반응, 캐릭터는 모름"으로 전달 (4차 벽 깨지 않도록 지시)
  - 📌 목록에서 하나씩 해제하거나 전체 반영을 끌 수 있어요.
- **자동 생성**: 설정에서 켜면 AI 답변 N번마다 뒤에서 조용히 새 피드를 만들고 알림을 띄웁니다.
- 슬래시 명령어: `/community` (창 열기), `/community platform=fivech mode=world 축제 당일 반응` (바로 생성)
  - platform: `naver` `dcinside` `reddit` `twitter` `fivech` `weibo` `tieba`
  - mode: `meta`(작품 반응) `world`(세계관 속)

## 화면 테마

커뮤니티 창 위쪽 ◐ 버튼(또는 설정의 "화면 테마")으로 **테마 따라가기 → 라이트 → 나이트** 순서로 바뀌어요.
- 테마 따라가기: 실리태번 테마 색(글자·배경·테두리·강조색)을 따라가요. 커뮤니티 상징색(네이버 초록 등)은 유지돼요.
- 라이트 / 나이트: 각 커뮤니티의 밝은 화면 / 어두운 화면 스타일로 보여요.

## 언어

- **생성 언어**: 커뮤니티 원어(2ch=일본어, 웨이보·티에바=중국어, Reddit=영어…) 또는 한국어·영어·일본어·중국어·스페인어·러시아어 등 목록에서 고르거나 **직접 입력**(예: Catalan, 경상도 사투리 한국어). 커뮤니티 창 생성 버튼 옆에서도 바꿀 수 있어요.
- **번역 함께 생성**: 원하는 언어로 번역을 같이 만들어 피드 위 **번역 보기**로 전환해요. 응답이 길어지니 최대 토큰을 넉넉히 주세요.

## 프롬프트 편집

설정 → 커뮤니티 피드 → **프롬프트 편집**에서 항목을 골라 고칠 수 있어요. (시스템 프롬프트, 두 모드 지시, 이어서 생성 지시, 내 글에 반응하라는 지시, 언어/번역 지시, 출력 형식, 커뮤니티별 스타일)

- 변수: `{{char}}` `{{user}}` `{{platform}}` `{{language}}` `{{translation}}` `{{count}}` `{{comments}}`, 실리태번 매크로도 사용 가능
- 비우거나 "이 항목 기본값으로"를 누르면 기본값으로 돌아가요.
- 출력 형식 항목을 고칠 때는 JSON 필드 이름(`posts`, `comments`, `reply_to`, `body`, `body_tr` 등)을 바꾸지 마세요. 확장이 이 이름으로 읽어요.

## 잘 안 될 때

- "응답을 해석하지 못했어요" → 최대 응답 토큰을 늘리거나 글/댓글 수를 줄여 보세요. 원본 응답 보기에서 AI가 뭘 보냈는지 확인할 수 있어요.
- 사고(thinking) 모델은 토큰을 많이 먹으니 최대 토큰을 넉넉히 주세요.
- 확장이 안 보이면 폴더 이름/위치와 브라우저 콘솔(F12)의 빨간 오류를 확인하세요.
